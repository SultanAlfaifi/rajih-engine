# Contributing

RAJIH is source-available, not open source. Reading, running, studying, and submitting proposed changes are permitted under `LICENSE`. Publishing or distributing modified copies is not permitted without written authorization.

1. Open an issue describing the problem and evidence.
2. Keep changes narrow and add meaningful tests.
3. Run `python -m unittest discover -s tests -v`.
4. State whether AI tools contributed and verify every external claim yourself.
5. By contributing, you grant the maintainer permission to incorporate the contribution into RAJIH under the project license; you retain copyright in your contribution.

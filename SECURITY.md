# Security policy

## Supported version

Only the latest release is supported while RAJIH is in alpha.

## Reporting a vulnerability

Do not open a public issue containing credentials, private hackathon material, or an exploitable vulnerability. Contact the copyright holder through a private GitHub security advisory.

RAJIH stores run data under `.rajih/`. Treat briefs, team details, evidence, and decision logs as potentially confidential. Never commit `.env` or `.rajih/` directories.
